Cisco IT Essentials
Virtual Desktop

Obtención segura 0/4

  • ✓Inscribirse en el curso IT Essentials dentro de Cisco Networking Academy (netacad.com) ↗, la plataforma oficial de Cisco.
  • ✓Ingresar con la cuenta del curso y ubicar la sección de recursos o actividades prácticas ("Virtual Desktop Activity").
  • ✓Descargar el archivo únicamente desde el enlace oficial que entrega la plataforma o el instructor.
  • ✓Descomprimir el archivo ZIP y abrir el index.html incluido para iniciar la actividad en el navegador.

⚠ Evitar descargarlo de sitios de terceros o enlaces "gratis": no garantizan la versión correcta ni la seguridad del archivo.

Logisim Evolution

Obtención segura 0/4

  • ✓Entrar al repositorio oficial en GitHub: github.com/logisim-evolution/logisim-evolution ↗.
  • ✓Ir a la sección Releases y elegir el instalador según el sistema operativo (.msi Windows, .dmg macOS, .deb/.rpm/.snap Linux).
  • ✓Descargar solo desde ese repositorio oficial, evitando sitios espejo con software adicional no deseado.
  • ✓Ejecutar el instalador descargado y seguir el asistente paso a paso.

⚠ Los paquetes oficiales (.msi/.dmg) ya incluyen el entorno de Java; no es necesario instalarlo aparte salvo que uses el archivo .jar universal.

↗ Ir a GitHub Releases
