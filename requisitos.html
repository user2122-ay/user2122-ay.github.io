Cisco IT Essentials
Virtual Desktop

Uso básico

  1. Abre el index.html de la actividad; espera a que cargue el entorno 3D.
  2. Usa el mouse para rotar la vista del gabinete y la rueda para acercar o alejar.
  3. Haz clic sobre una pieza resaltada para seleccionarla y ver su nombre.
  4. Arrastra la pieza fuera del gabinete para extraerla, y de vuelta a su ranura para reinstalarla.
  5. Sigue el orden sugerido por la actividad: fuente de poder → placa madre → RAM → almacenamiento → tarjetas de expansión.

Logisim Evolution

Uso básico

  1. Abre Logisim Evolution; se crea automáticamente un circuito nuevo en blanco.
  2. En el panel izquierdo, elige una compuerta (AND, OR, NOT…) de la biblioteca "Gates".
  3. Haz clic en el lienzo para colocarla; repite para añadir más compuertas.
  4. Usa la herramienta de cableado para conectar las salidas y entradas entre sí.
  5. Agrega un "Pin" de entrada y uno de salida para poder probar el circuito en vivo.
  6. Activa el modo de simulación y haz clic en los pines de entrada para ver el resultado.
